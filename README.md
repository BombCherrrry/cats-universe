# Cat's Universe

Библиотека комиксов с реакциями, комментариями и общим чатом.

- Как запустить сайт — см. **SETUP.md**
- Как добавить новый комикс — см. **HOW-TO-ADD-COMIC.md**

Стек: статичный HTML/CSS/JS (GitHub Pages) + Supabase (бесплатная база данных для реакций/комментариев/чата). Аккаунтов для читателей не требуется — только имя при первом визите.
