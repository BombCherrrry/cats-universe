Загрузка комикса

Нужен личный токен GitHub с доступом к этому репозиторию — он хранится только в этом браузере, никому не виден. Инструкция ниже.

Как получить: GitHub → фото профиля → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token. Repository access — выбери только этот репозиторий (). Permissions → Contents → Read and write. Сгенерируй и скопируй сюда.
