# Как залить новый комикс

Без кода — только файлы и один список. Занимает минут 5.

## 1. Подготовь картинки

Каждая страница — отдельный файл (webp/jpg/png). Назови их по порядку:
`1.webp`, `2.webp`, `3.webp`, ...

## 2. Создай папку комикса

В GitHub-репозитории, в папке `comics/`, создай новую папку для комикса. Имя папки — латиницей, без пробелов, это и есть его `slug`, например:

```
comics/novyy-vypusk/
```

Загрузи туда все файлы страниц (в GitHub: открой папку → Add file → Upload files → перетащи картинки).

## 3. Впиши комикс в список

Открой файл `data/comics.json`, добавь новый объект в массив `comics` (не забудь запятую после предыдущего):

```json
{
  "slug": "novyy-vypusk",
  "title": "Название выпуска",
  "subtitle": "Deluxe",
  "author": "Твоё имя",
  "added": "2026-09-20",
  "cover": "comics/novyy-vypusk/1.webp",
  "pageCount": 24,
  "pagesBase": "comics/novyy-vypusk/",
  "pagesFullBase": "comics/novyy-vypusk/",
  "pageExt": "webp"
}
```

Поля:
- `slug` — совпадает с именем папки
- `pageCount` — сколько всего страниц
- `cover` — какая картинка показывается обложкой в библиотеке (обычно первая страница)
- `added` — дата в формате ГГГГ-ММ-ДД (по ней сайт понимает, что показать бейдж «Новое» первые 2 недели)
- `pageExt` — расширение файлов страниц (webp / jpg / png — как у тебя)

Сохрани файл (Commit changes).

## Готово

Через минуту-две GitHub Pages обновит сайт, и комикс появится в библиотеке — с чистой веткой обсуждения и реакциями с нуля.
